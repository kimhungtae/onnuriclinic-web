## 0. 프로젝트 개요

### 0.1 목적
환자 자가 설문에서 시작하여 원장의 체질 확진과 처방 추천까지 이어지는 **사상체질 진료 전 과정의 디지털 도구**를 구축한다. 안준철 원장의 **배제법(排除法) 방법론**을 디지털화하여, 자가 설문만으로 명확하지 않은 혼동 케이스에서도 체계적인 확증·확진 워크플로우를 제공한다.

### 0.2 핵심 임상 원칙 (전 모듈 공통)
1. **배제법 우선** — 체질은 직접 선택이 아니라 불가능한 체질을 제외하여 결정
2. **체질 + 한열 + 음양형 + 변증** 4축이 모두 맞아야 처방이 결정됨
3. **약물 반응이 외모·체격 판단보다 우선한다** (안준철)
4. **한 가지 증상 호전만으로 체질·처방을 확정하지 않는다** (안준철)
5. **결정타 한 개가 약한 단서 여러 개보다 강하다**

### 0.3 6단계 진료 흐름

```
STEP 1  자가 설문지 (환자용)
   ↓
STEP 2  HTML 앱 설문 결과 산출 (자동)
   ↓
STEP 3  의사결정나무 — 시진/소증/성정 (원장용)
   ↓ (신뢰도 70% 미만 시)
STEP 4  정밀 시진 차트 (혼동 페어별 6종)
   ↓ (양쪽 결정타 충돌 또는 미확정 시)
STEP 5  기능 검사 차트 (맥진·복진·반응·약물시험)
   ↓ (체질·한열·음양형 확정)
STEP 6  처방 추천 모듈 (주소증 기반)
   ↓
처방 확정 · 재진 추적
```

## 2. 모듈별 상세 명세

### 2.1 모듈 C — 정밀 시진 차트

#### 진입 조건
의사결정나무(STEP 3) 결과 신뢰도 70% 미만이면서 두 체질이 후보로 남은 경우, 자동으로 해당 페어 차트로 분기.

#### 공통 화면 구조
1. **상단 헤더** — 페어명 표시 (예: "태음인 ↔ 소양인 변별 차트")
2. **설문 결과 바** — 자가설문에서의 두 체질 비율 (예: "태음 42% / 소양 38%")
3. **판정 원칙 안내** — ★ / ★★ 표기 설명
4. **비교 테이블** — 4~5개 카테고리, 좌우 2열 (체질별)
5. **결과란** — ★★ 결정타 카운트 + ★ 일반 단서 카운트
6. **판정 로직 박스** — 3가지 분기 명시
7. **최종 판정 버튼** — 확정 / 보류 → 기능검사

#### 판정 로직 (전 페어 공통)
```
조건 1: 한쪽에만 ★★ 결정타가 체크됨
       → 그 체질로 확정 (STEP 6로 진행)

조건 2: 양쪽 모두 ★★ 결정타 체크됨
       → 보류, STEP 5 기능 검사로

조건 3: 양쪽 모두 ★★ 없음
       → ★ 일반 단서 개수 비교
       → 3개 이상 차이: 다수 쪽 확정
       → 1~2개 차이: STEP 5 기능 검사로
```

#### 카테고리별 항목 (페어마다 다름, C-1 태음↔소양 예시)
- **CAT 1 흉곽 형태** — 원통형 vs 역삼각, 흉골각 폭
- **CAT 2 엉덩이·하체 안정감** — 어깨>엉덩이가 결정타
- **CAT 3 얼굴·기세** — 이목구비 분포, 안색
- **CAT 4 입 크기** — 강력한 배제 지표
- **CAT 5 음용수·구갈** — 입천장/코 마름 vs 인후부 마름

#### 6 페어별 카테고리 (개발 우선순위 순)
1. **C-1 태음 ↔ 소양** (mockup 완성)
2. **C-2 태양 ↔ 소음** — 다리길이 비율 / 코끝방울 / 눈빛 (하만종 강조점)
3. **C-3 태음 ↔ 소음** — 흉곽 형태 / 엉덩이 모양 / 피부 질감
4. **C-4 소양 ↔ 소음** — 입 크기 / 엉덩이 / 동작
5. **C-5 태양 ↔ 태음** — 머리 비율 / 목 굵기 / 피부
6. **C-6 태양 ↔ 소양** — 어깨 / 머리 비율 / 안색

각 페어의 구체적 항목은 안준철·하만종·권재식 자료에서 추출하여 ★/★★ 가중치를 부여하여 작성한다.

### 2.2 모듈 D — 기능 검사 차트

#### 진입 조건
정밀 시진(STEP 4)에서 보류 판정이 난 경우 자동 진입.

#### 4개 섹션 구조

##### 섹션 D-1 맥진
| 검사 항목 | 소견 1 | 소견 2 |
|---|---|---|
| 기본맥 강도 | 장이긴 (태음) | 미세불현 (소양) |
| 관맥 부위별 | 촌맥 강 → 양형 | 척맥 강 → 음형 |
| 맥의 한열 | 침지 → 한 | 부삭 → 열 |

##### 섹션 D-2 복진
| 검사 항목 | 소견 1 | 소견 2 |
|---|---|---|
| 상복부 가스 | 잘 참 (소양 한자) | 안 참 (소양 열자) |
| 심하부 압통 | 두툼·없음 (태음) | 압통 (소양) |
| 대변 빈도 | 1일 1회 이상 (한증) | 1~2일 1회, 변비 (열증) |

##### 섹션 D-3 반응 확인 (히든카드)
| 검사 항목 | 결과 의미 |
|---|---|
| 커피 반응 | 잘 잠 (태음 양형) / 불면 (태음 음형) / 심계 (소양) |
| 산약 반응 | 복통 → 태음 배제 |
| 우유 반응 | 설사·복통 → 태음 가능성 낮음 |
| 평생 못 먹는 음식 | 자유 기재 (양파 → 태양, 메밀 → 태음 등) |
| 홍삼 반응 | 열감·답답 → 소양 열자 |

##### 섹션 D-4 약물 시험 (최종 확진)
**테스트 처방 (체질·한열별)**
| 후보 | 처방 |
|---|---|
| 태음 한자 | 태음조위탕 |
| 태음 열자 | 갈근조위탕 |
| 소양 한자 | 형방지황탕 / 형방패독산 |
| 소양 열자 | 지황백호탕 / 양격산화탕 |

**4대 적합성 기준 (안준철)**
- 대변 / 소변 / 수면 / 피로감
- **3개 이상 호전 시 적합 판정**
- 단독 증상 호전만으로 판정 금지 (안준철 원칙)
- 피부 건조는 계절적 원인일 수 있어 기준 제외

#### 종합 판정 출력
체질·한열·음양형 3가지를 동시 확정하여 STEP 6로 전달.

### 2.3 모듈 E — 처방 추천 모듈

#### 진입 조건
체질·한열·음양형이 확정된 후 자동 진입.

#### E-1 환자 요약 카드 (자동 전달 데이터)
```json
{
  "constitution": "태음인",
  "cold_heat": "한증",
  "yang_yin_form": "양형",
  "evidence_path": "정밀시진 + 기능검사 + 태음조위탕 7일 (3/4 호전)"
}
```

#### E-2 주소증 입력
- **자주 쓰는 주소증 칩** — 체질·한열별로 자동 필터링되어 노출
  - 태음 한증: 만성 비염, 식적, 변비 경향, 기침 가래, 보약, 감기 후 회복, 관절통, 사경증, 코피, 땀 많음 등
  - 태음 열증: 안면홍조, 두통, 불면, 가슴답답, 변비, 다한증, 공황장애 등
  - 소양 한증: 상복부 가스, 우울, 두통, 이명, 한기, 간기울결 증상 등
  - 소양 열증: 갈증, 위완 건조, 소갈, 다음, 흉번조, 안충혈 등
  - 소음: 소화불량, 무기력, 설사, 대변 묽음, 한기 등
- 다중 선택 가능 (최대 3개 권장)
- 자유 기재란 (병력·부소증·특이사항)

#### E-3 처방 매칭 엔진 (백엔드 로직)
**매칭 기준 (가중치)**
1. 체질 일치 (필수, 40%)
2. 한열 일치 (필수, 25%)
3. 음양형 일치 (태음만, 15%)
4. 주소증 부합도 (변동, 20%)

**매칭도 % 계산** — 위 가중치 합산하여 0~100% 표시

**데이터베이스 구조 (각 처방)**
```
처방명: 태음조위탕
체질: 태음인
한열: 한증
음양형: 양형
주증: [위완수한증, 중기 회복, 비병, 식적, 한습곤비, 외감]
주의: [마황 함유 → 음허·심계 부적합]
부적합 시그널: [불면, 심계, 구갈, 피부건조]
대체 처방: [갈근조위탕(열자 전환), 음형 처방]
임상례 가감: [
  "+갈근 2돈, 승마 1돈 (비병·표열)",
  "+산약·연자육 각 2돈 (보비·보신, 변비)",
  "+대황 3푼 (술 많이 마시는 환자)"
]
출처: 안준철 강의록, 사상임상의학회
```

#### E-4 추천 처방 카드 (3순위까지)
각 카드:
- 처방명 + 한자명
- 매칭도 % + 시각화 바
- **추천 근거** (왜 이 처방인지)
- **주의** (부작용·금기·체크포인트)
- **부적합 시그널** (어떤 사이드 나오면 변경)
- **본 케이스 가감** (임상례 기반 가미법)
- 액션 버튼: [이 처방으로 선택] [구성 상세] [유사 처방 비교]
- 출처 표시 (어느 자료에서 추출됐는지)

#### E-5 최종 처방 결정란
- 선택 처방 표시
- 처방 기간 / 재진 시점 (D+7, D+15 등)
- 처방 의도 메모
- 액션: [처방 확정 · 차트 저장] [PDF 출력] [재진 추적 등록]

#### E-6 재진 추적
- D+7, D+15 등 설정한 재진 시점에 자동 체크리스트 제시
- 4대 적합성 기준 (대변·소변·수면·피로감) 변화 입력
- 부적합 시그널 발생 시 자동으로 대체 처방 후보 제시

### 2.4 모듈 F — 시스템 공통

#### F-1 환자 데이터 모델
환자 한 명에 대해 누적되는 데이터:
```
- 기본 정보 (이름, 나이, 성별, 연락처)
- 자가설문 결과 (체질별 % + 답변 raw)
- 의사결정나무 진행 기록 (게이트별 선택·배제·skip)
- 정밀 시진 결과 (사용한 페어, 체크 항목, 판정)
- 기능 검사 결과 (맥·복·반응·약물시험 결과)
- 확정 체질·한열·음양형
- 주소증 (방문별)
- 처방 이력 (방문별, 처방명·가감·기간)
- 재진 추적 (적합성 점수 변화)
- 원장 메모
```

#### F-2 모듈 간 자동 분기 로직
```
설문지 결과 ≥70% → STEP 3 의사결정나무 (간단 확인) → STEP 6 처방
설문지 결과 <70% → STEP 3 → STEP 4 정밀시진 → STEP 6
정밀시진 보류 → STEP 5 기능검사 → STEP 6
약물시험 미적합 → 후보 재평가 (STEP 4로 되돌아감)
```

#### F-3 진료 차트 출력
- 환자별 전체 진료 흐름 PDF 출력
- 인쇄용 A4 (종이 차트 호환)
- 출력 항목: 설문 결과, 의사결정 근거, 확정 체질, 처방 내역, 재진 결과

#### F-4 임상례 데이터베이스
- 안준철·하만종·권재식 자료에서 추출한 처방 가감 사례
- 처방 + 주소증 + 가감약 + 결과 형태로 저장
- 처방 추천 시 "본 케이스 가감" 자동 제시에 활용

## 7. 주의사항 (Cowork 작업 시)

1. **이 시스템은 의료기기가 아닌 임상 의사결정 지원 도구**임을 명확히 명시. 최종 진단·처방은 원장 책임.
2. **"추천 처방" 표기 사용** — 자동 처방 도구로 오인되지 않도록.
3. **안전 안내문 필수** — 각 처방 화면 하단에 안준철 원장 원칙 2가지 명시:
   - "한 가지 증상의 호전만으로 체질·처방을 확정하지 않는다"
   - "체질과 한열은 항상 전제로 하고 약물 적합성을 확인해야 한다"
4. **부적합 시그널 명시** — 모든 처방에 "이런 증상 나오면 즉시 재평가" 안내 포함.
5. **임상례 출처 표시** — 모든 처방·가감에 출처(안준철·하만종 등) 표기.
6. **모바일 대응** — 진료실 태블릿에서도 사용 가능하도록 반응형 설계.
7. **인쇄 호환** — A4 차트 출력이 깨끗하게 나와야 함 (종이 차트 병행 운영).
