▣ 단계 간 데이터 전달

STEP 1→2 25문항 raw 응답
STEP 2→3 체질별 점수 % + 답변 데이터
STEP 3→4 후보 체질 페어 + 신뢰도 + 게이트별 선택·배제
STEP 4→5 ★/★★ 체크 결과 + 잠정 체질
STEP 5→6 확정 체질 + 한열 + 음양형 + 감별 근거
STEP 6→재진 처방 내역 + 부적합 시그널 추적 항목

▣ 개발 우선순위 (Phase 별)

PHASE 1 핵심 신규 모듈 + 기존 이슈 해결 2~3주
  • 모듈 C-1 (태음↔소양) 실제 구현
  • 모듈 D 전체 (기능 검사)
  • 모듈 E MVP (E-1, E-2, E-4, E-5)
  • 모듈 B 잔존 이슈 해결 (판정 패널 디자인, 다중 후보 결과 반영)
PHASE 2 정밀화 + 매칭 엔진 고도화 3~4주
  • 모듈 C-2~C-6 (정밀 시진 나머지 5종 페어)
  • 모듈 E-3 매칭 엔진 고도화 (가중치·임상례 DB 연계)
  • 모듈 E-6 재진 추적 시스템
  • 모듈 F-1 환자 데이터 모델 통합
