태음조위탕 太陰調胃湯
매칭도
92%
추천 근거 태음인 한증의 위완수한증·중기 회복의 핵심 처방. 비병(소화불량·더부룩)·식적·소장허한·한습곤비에 두루 적합. 환절기 비염의 외감 동반 시에도 1차 선택지.
주의 마황 함유 → 음허·심계·불면자에게 부적합. 본 환자는 양형이라 사용 가능. 술 많이 마시는 환자엔 대황 3푼 가미 고려.
부적합 시그널 복용 후 불면·심계·구갈·피부건조 발생 시 → 음형으로 재평가, 음허 동반 가능성. 갈근조위탕 또는 음형 처방으로 전환.
▣ 본 케이스 가감 (안준철 임상례 기반)
태음조위탕 + 갈근 2돈, 승마 1돈 (비병·표열 겸함) / 산약·연자육 각 2돈 (보비·보신, 변비 경향 대응)
안준철 강의록 · 사상임상의학회

마황의이인탕 麻黃薏苡仁湯
매칭도
74%
추천 근거 태음인 한자 풍한습비증의 기본방. 비염이 관절통·어깨결림을 동반하고 환절기·습한 날씨에 악화되는 경우 적합. 본 환자의 어깨 결림 동반 소견과 부합.
주의 마황 함유 → 음허·심계자 부적합. 식적·변비가 주증이면 1순위 선택. 풍한습비증이 비염보다 우세할 때 우선 선택.
부적합 시그널 설사 빈발 또는 무기력 → 의이인 감량 또는 태음조위탕으로 전환.
사상임상의학회 (한자 풍한습비)

조위승청탕 調胃升淸湯

62%
추천 근거 태음인 한증의 심비기허·한습곤비에 쓰임. 비병 + 어지럼증·두통·사경증 등 청양불승 소견이 있을 때 적합. 본 환자는 부소증으로 어깨결림이 있어 보조 후보.
주의 주소증이 식적·변비보다 두통·현훈·사경증 쪽으로 기울 때 우선 선택. 본 케이스에서는 1·2순위 부적합 시 고려.
