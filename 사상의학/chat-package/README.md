## ⚠️ 작업 시 반드시 지킬 7가지 원칙

### 1. 이 시스템은 **의료기기가 아닌 임상 의사결정 지원 도구**
- 최종 진단·처방은 원장 책임
- UI 어디에서도 "자동 진단" "AI가 처방 결정" 같은 표현 금지
- "추천" "후보" "참고" 어휘 사용

### 2. 모든 처방 화면에 안전 안내문 필수
다음 2가지를 반드시 표기:
- "한 가지 증상의 호전만으로 체질·처방을 확정하지 않는다" (안준철)
- "체질과 한열은 항상 전제로 하고 약물 적합성을 확인해야 한다" (안준철)

### 3. 임상 자료 출처 표시
모든 처방·가감·변별 항목에 출처(안준철·하만종·권재식 등) 표기.

### 4. 환자 개인정보 보호
- 환자 데이터 영속화 방식은 **의뢰자와 상의 후 결정** (LocalStorage / 별도 DB / 클라우드)
- 외부 전송 절대 금지
- 통계·분석 기능을 임의로 추가하지 말 것

### 5. 인쇄 호환성 유지
종이 차트(A4) 출력이 깨끗하게 나와야 함. 종이 차트와 디지털 시스템 병행 운영.

### 6. 모바일·태블릿 대응
진료실 태블릿에서 사용 가능하도록 반응형 설계. 정확한 대상 디바이스는 의뢰자와 확인.

### 7. **변경 사항은 작은 단위로**
이 프로젝트의 작업 원칙:
- 큰 일괄 변경 ❌
- 한 모듈씩, 작은 변경 단위 ✅
- UI 변경 전에는 mockup 먼저 보여주고 합의 받기
- 토큰·시간 효율 고려, 점진적 개선

## 🧭 사상체질 기본 용어 (개발자 참고)

한의학 비전공자를 위한 최소한의 용어 안내입니다.

| 용어 | 의미 |
|---|---|
| **사상체질 (四象體質)** | 인간을 4가지 체질로 분류 (태양인·태음인·소양인·소음인). 동무 이제마의 사상의학에서 유래 |
| **태양인 (太陽人)** | 가장 드문 체질 (전체 0.1%). 머리 크고 하체 가늚 |
| **태음인 (太陰人)** | 가장 흔한 체질. 원통형 체형, 흉곽 발달, 입 큼 |
| **소양인 (少陽人)** | 어깨 발달·엉덩이 작음, 역삼각 체형 |
| **소음인 (少陰人)** | 엉덩이 발달·상체 좁음, 사다리 체형 |
| **한열 (寒熱)** | 같은 체질 내에서도 추위 잘 타는지(寒) 더위 잘 타는지(熱)로 나뉨 |
| **음양형 (陰陽形)** | 태음인만 추가로 양형/음형 구분 (양허 vs 음허) |
| **배제법 (排除法)** | 안준철 원장의 핵심 방법론 — 아닌 체질을 제외해 가며 확정 |
| **시진 (視診)** | 외모·체형 관찰을 통한 진단 |
| **소증 (素證)** | 평소 증상·습관 |
| **성정 (性情)** | 성격·기질 |
| **변증 (辨證)** | 증후를 분류하여 병의 본질을 판별 |
| **결정타 (★★)** | 한 항목만으로 체질을 확정/배제할 수 있는 강력한 변별점 |
| **부적합 시그널** | 처방 복용 후 발생하면 처방 변경이 필요한 증상 |
