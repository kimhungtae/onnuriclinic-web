# 사상의학 체질 플랫폼 — 종합 설계서

> **목적**: `사상의학/` 폴더의 원전·강의록·처방·본초·감별 자료를 통합한 사상의학 디지털 플랫폼의 설계 청사진.
> 본 문서는 **Claude Code에서의 구현을 위한 명세서**다. 모든 코딩은 Claude Code에서 진행.
>
> **작성일**: 2026-05-18 · **버전**: v1.0 (초안)

---

## 0. TL;DR — 한눈에 보는 플랫폼

- **이름(가칭)**: 사상온누리 (Sasang Onnuri Platform)
- **형태**: 웹 플랫폼 + 향후 데스크톱 패키징(Tauri) 옵션
- **추천 스택**: **Next.js 14 (App Router) + TypeScript + SQLite (Drizzle ORM) + MeiliSearch + Tailwind/shadcn-ui**
- **사용자 4계층**: ① 한의사·임상가 ② 학생·연구자 ③ 일반인(자가진단) ④ 운영자(관리자)
- **4대 모듈**: ① 체질 감별 ② 처방·본초 DB ③ 장부변증 가이드 ④ 강의록·자료 라이브러리
- **데이터 전략**: **하이브리드** — 핵심 자료는 구조화 DB, PDF/HWP 원본은 메타데이터+뷰어로 보존

## 1. 비전과 가치 제안

### 1.1 문제 정의
- 사상의학 자료는 HWP/PDF/카톡 강의록 등 **흩어진 비정형 문서**로 존재 → 검색·교차참조 불가
- 류주열 처방 350+, 안준철 본초, 김주 강의록 등 양질의 자료가 **개인 PC에서만 활용**
- 일반인은 정확한 체질 감별 도구 부재, 한의사는 임상 시 빠른 처방 레퍼런스 부재

### 1.2 플랫폼의 약속
| 사용자 | 무엇을 얻는가 |
|---|---|
| **한의사·임상가** | 진료 중 처방·본초·변증을 1초 검색. 체질×증상 교차 필터 |
| **학생·연구자** | 강의록 전문검색, 북마크, 학습 트리(개요 → 장부변증 → 처방) |
| **일반인** | 28문항 자가진단 + 4체질별 섭생·식이 가이드 |
| **운영자(본인)** | 자료가 늘어도 한 곳에 쌓이는 영구 지식베이스 |

### 1.3 면책 원칙(설계에 반영)
- 일반인 모드의 자가진단 결과 화면 상·하단에 **"본 결과는 참고용이며 정확한 진단은 한의사 진료를 받으세요"** 고정 노출.
- 처방 페이지(전문가 영역)는 **비공개/로그인 전용** 또는 워터마크.

| **이론 보충** | 식치와 체질식이요법에 대한 문헌고찰.pdf | PDF | 메타+뷰어 |

### 2.2 핵심 데이터셋 사이즈 (확인됨)
- **체질설문지**: 28문항 × 4지선다, 70% 임계값 (1=태양·2=태음·3=소음·4=소양)
- **류주열 처방 DB**: 4시트(체질별) — **태양 72 / 태음 132 / 소양 74 / 소음 74 ≈ 약 352 처방**
  - 컬럼: `No.`, `처방명`, `구성(개정)`, `구성(예전)`
  - ID 컨벤션: **L**(태양) / **H**(태음) / **P**(소양) / **R**(소음)
- **장부변증**: 폐·대장 / 비·위 / 간·담 / 신·방광 / 심·소장 — 5쌍 × 4체질 매트릭스

## 4. 핵심 기능 명세

### 4.1 모듈 A — 체질 감별 (Discriminator)

#### 4.1.1 입력
1. **성인 28문항** (현재 `체질설문지.txt`)
2. **소아 문진** (현재 `소아체질문진.hwp` — 별도 분기, 8~12문항 예상)
3. **음양 편차 기반 시각 감별** (`음양의 편차로본 체질감별.pdf` — 얼굴 사진 분석은 v2, 우선은 체크리스트화)
4. **얼굴형·체격 감별 표** (`체질감별.pdf`, `사상인 감별.pdf` — 보조 입력으로 5~7문항)

#### 4.1.2 알고리즘 (v1: 가중 카운팅)
```
for q in answers:
    score[choice_label] += weight[q]  # 기본 weight=1, 핵심문항 weight=2
result = argmax(score)
confidence = score[result] / sum(score)
if confidence < 0.70:
    result = "감별 불확실 — 한의사 진료 권장"
```
- **확장(v2)**: 베이지안 가중치 학습, 한의사 라벨링 데이터 누적 시 ML
- **가중치 테이블**: 폐대간소(태양인 특이문항) > 일반문항. `weights.json` 파일로 외부화.

#### 4.1.3 출력
- 4체질 막대그래프 (Recharts)
- 1차 추정 + 2차 후보
- 추정 근거 문항 5개 하이라이트
- "다음 단계" 카드: 섭생법 / (전문가 모드) 처방 후보

#### 4.1.4 화면 와이어
```
┌──────────────────────────────────────────┐
│  [1/28] 체격은 어떠합니까?               │
│  ○ 가슴이 크고 하리가 약하다 (태양)      │
│  ○ 하리가 크고 가슴이 약하다 (태음)      │
│  ○ 상하체가 약하고 중부가 작다 (소음)    │
│  ○ 중부가 크고 상하체가 약하다 (소양)    │
│  [← 이전]                  [다음 →]       │
│  ▓▓▓░░░░░░░░░░░░░░░░  4% (1/28)        │
└──────────────────────────────────────────┘
```

### 4.2 모듈 B — 처방·본초 검색 DB (Prescription & Materia Medica)

#### 4.2.1 처방 검색 화면
- **필터 패널**:
  - 체질: ☐ 태양 ☐ 태음 ☐ 소양 ☐ 소음
  - 약재 포함: `갈근`, `+황금`, `-마황` (논리 연산)
  - 증상 태그: 표열·이한·피부·소화·두통…
  - 출처: 류주열 / 안준철 / 새로사상책
- **결과 리스트**: 카드 (처방명 · 체질 배지 · 구성 미리보기 · 출처)
- **상세 페이지**: 구성표(개정/예전 대조), 효능, 적응증, 연관 처방, 변증 분류

#### 4.2.2 본초 사전
| 필드 | 설명 |
|---|---|
| 약재명 | 갈근, 백부근… |
| 체질 분류 | 태음(주로) / 태양 보조… |
| 강약 분류 | 강·중·약 (김기현 분류) |
| 귀경 | 폐·비·간·신·심 |
| 사기오미 | 한열온량 / 산고감신함 |
| 주치/효능 | |
| 권재식/안준철 코멘트 | 카톡강의 발췌 |
| 사용된 처방(역참조) | 자동 계산 |

#### 4.2.3 약재 토큰 파싱 (XLSX → DB)
구성 문자열 `"갈근8 맥문동6 황금6 길경4"` → 정규식 `([가-힣]+)(\d+(?:\.\d+)?)` 으로 분리
- `(약재명, 용량_돈)` 튜플 시퀀스
- 정규화: 이체자 매핑 테이블 (예: 모당귀 ↔ 당귀)

### 4.3 모듈 C — 장부변증 가이드

#### 4.3.1 데이터 구조 (트리)
```
장부(肝/心/脾/肺/腎)
  └─ 부(膽/小腸/胃/大腸/膀胱)
       └─ 체질(태양/태음/소양/소음)

                 ├─ 권장 처방 (FK → 처방 DB)
```

#### 4.3.2 화면
- 좌측: **장부 다이어그램** (인체 위 클릭형 SVG)
- 우측: 선택된 장부 × 체질의 변증 카드들
- 카드 클릭 → 변증 상세 + 연관 처방 카드 자동 표시
- 자료 출처: `새로 쓴 사상의학 장부변증 (폐병/비병/간병/신병/심병)` 5개 HWP

### 4.4 모듈 D — 강의록·자료 라이브러리

#### 4.4.1 컬렉션
- **김주 선생님** — 강의, 사상강의록
- **안준철 원장** — 2009 강의록, 2012 강의록, 카톡강의, 본초 카톡강의, 변증관
- **권재식** — 카톡모음
- **이제마** — 국역동의수세보원

#### 4.4.2 기능
- 전체 텍스트 검색 (MeiliSearch)
- 강의자 / 주제 / 연도 필터
- **인용 가능한 단락 단위**(paragraph)로 색인 → 검색결과에 페이지+단락 표시
- 하이라이트, 북마크, 노트(학생 이상)

#### 4.4.3 자료 처리 파이프라인
```
원본(HWP/PDF) → 변환(LibreOffice/pypdf) → 텍스트(.md)
            → 단락 분리(heading/blank line)
            → 메타데이터(저자·문서·페이지·연도)
            → MeiliSearch index
원본은 그대로 /static/sources/ 에 보관 → 뷰어에서 다운로드 가능
```

## 5. 데이터 모델 (스키마)

> Drizzle ORM(TypeScript) 기준. Postgres 대안도 동일 스키마 적용 가능.

```ts
// constitutions
type Constitution = '태양인' | '태음인' | '소양인' | '소음인';

// users
users { id, email, name, role: 'guest'|'public'|'student'|'clinician'|'admin', createdAt }

// questionnaires
questionnaires { id, type: 'adult28'|'pediatric'|'visual', version, weightsJson }
questions      { id, qnaireId, order, text, isCore: bool }
choices        { id, questionId, order, label, constitutionKey: 1|2|3|4 }
responses      { id, userId, qnaireId, startedAt, finishedAt }
answers        { id, responseId, questionId, choiceId }
results        { id, responseId, top: Constitution, scoresJson, confidence: 0..1 }

// prescriptions
prescriptions {
  id: 'L001'|'H001'|...,
  constitution: Constitution,
  name: text,               // 류씨오가피장척탕
  compositionCurrent: text, // 원문
  compositionLegacy: text,
  source: text,             // '류주열' | '안준철' | '새로사상책'
  indications: text[],      // 적응증 태그
  notes: text
}
prescription_ingredients {
  id, prescriptionId, herbId, dose_don: float, version: 'current'|'legacy', order
}

// herbs (본초)
herbs {
  id, name, aliases: text[],
  constitutions: Constitution[],   // 주로 쓰는 체질
```

## 8. 자료 마이그레이션 전략 (ETL)

### 8.1 단계별 자동화 수준

| 자료 | 추출 | 정규화 | 자동/수동 |
|---|---|---|---|
| 체질설문지.txt | 텍스트 직접 사용 (인코딩 복원 필요) | 28문항 JSON 변환 | 반자동(스크립트+검수) |
| 류주열 XLSX | openpyxl로 4시트 읽기 | `parse-composition.ts` 정규식 토큰화 | 자동 |
| 본초 HWP | hwp5txt 또는 hwp5html 변환 | 표 부분만 추출 → CSV | 반자동 |
| 장부변증 HWP (5종) | hwp5txt | 구조 표 적은 편 → 수동 매핑 | 수동 + 템플릿 |
| 강의록 PDF | pypdf / pdfplumber | 단락 분리 + 메타 입력 | 자동 추출, 메타 수동 |
| 체질감별 표 PDF | OCR(필요시) | 표 정규화 | 반자동 |

### 8.2 HWP 처리
- **권장**: 1차 LibreOffice CLI(`soffice --headless --convert-to txt`)로 일괄 → 텍스트 검수
- 표가 깨질 경우 `hwp5proc` 도구로 XML 추출 → 파이썬 파서
- 안 되는 파일은 HWP → PDF 변환 후 동일 파이프라인

### 8.3 인코딩 주의
- `체질설문지.txt`는 CP949(EUC-KR)로 저장됨 → `iconv -f CP949 -t UTF-8` 필수

## 11. 보안·법적 고려

1. **의료 자문 면책**: 모든 결과 페이지에 고정 면책 고지. 일반인이 "처방"을 직접 볼 수 없게 RBAC.

   - 류주열 처방, 안준철 강의록, 김주 강의록 등은 **권리자 확인 후** 공개 범위 결정

   - 원전(동의수세보원)은 공유 가능, 국역본은 번역자 권리 확인
3. **개인정보**:
   - 자가진단 응답은 익명 저장 (회원 가입 시에만 식별)
   - PIPA 처리방침 페이지 필요
4. **접근 로그**: 처방·강의록 열람 로그 → 부정 사용 방지
